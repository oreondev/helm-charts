Oreon IT Helm charts

Production building blocks for Kubernetes reliability, observability and cost. Source, docs and issues on GitHub.

helm repo add oreonit https://oreondev.github.io/helm-charts
helm repo update
helm search repo oreonit/
ChartVersionDescription
alertmanager-routing-baseline0.1.0Alertmanager routing from one values file - teams, page and ticket receivers (Slack, PagerDuty, Opsgenie, email, Teams, webhook), severity routing, critical-inhibits-warning and page-inhibits-ticket rules, business-hours mute windows and a Watchdog sink. Rendered as an AlertmanagerConfig for the Prometheus Operator.
blackbox-slo-probes0.1.0Synthetic monitoring with SLOs - a list of URLs becomes Prometheus Operator Probe objects for the blackbox exporter, availability and latency SLOs with multi-window burn-rate page and ticket alerts, probe-down and TLS-expiry alerts, and a Grafana dashboard.
gateway-api-baseline0.1.0A shared Kubernetes Gateway API ingress baseline - one Gateway per cluster or environment with HTTP-to-HTTPS redirect, TLS listeners per hostname, namespace-scoped route attachment, HTTPRoutes and GRPCRoutes from values with timeouts and security headers filled in, automatic ReferenceGrants, a catch-all backend and BackendTLSPolicies. Works with GKE Gateway, Envoy Gateway, NGINX Gateway Fabric, Istio, Cilium and Traefik.
k8s-cost-waste-alerts0.1.0Find the money hiding in a Kubernetes cluster - recording rules, alerts and a Grafana dashboard for requests far above usage, under-committed nodes, idle PersistentVolumeClaims, LoadBalancers with no endpoints, HPAs stuck at max or pinned, containers without requests and workloads scaled to zero for weeks. Priced in your currency. Needs only kube-state-metrics and cAdvisor.
kyverno-production-policies0.1.1The Kubernetes production-readiness checklist as Kyverno policies - requests and limits, probes, owner labels, no latest tags, PodDisruptionBudgets and spread for multi-replica workloads, no NodePorts, nothing in the default namespace. Audit mode by default, enforce per namespace.
namespace-baseline0.1.0Guardrails for every team namespace from one values file - Pod Security Admission labels, ResourceQuota, LimitRange, default-deny NetworkPolicies with the usual allows (DNS, same namespace, ingress controller, monitoring), RBAC bindings for team groups and optional quota alerts.
otel-collector-baseline0.1.2A production OpenTelemetry Collector layout for Kubernetes as values for the OpenTelemetry Operator - a node agent (OTLP, kubelet and host metrics, container logs, Kubernetes metadata) feeding a gateway (health-check filtering, attribute redaction, tail sampling) that exports to OTLP backends, Google Cloud, Prometheus remote write, Datadog or Elasticsearch, plus auto-instrumentation, RBAC, alerts and a dashboard.
slo-burn-rate-alerts0.2.1SLOs as values. Generates Prometheus recording rules, multi-window multi-burn-rate page and ticket alerts, and a Grafana SLO / error-budget dashboard for Prometheus Operator and kube-prometheus-stack.
velero-backup-schedules0.1.0A backup policy for Velero as values - daily, weekly and monthly Schedules with retention, optional BackupStorageLocation and VolumeSnapshotLocation, a scheduled restore test that restores the latest backup into a scratch namespace and checks the pods come up, and alerts for failed, partial or stale backups. Velero itself is not included.
